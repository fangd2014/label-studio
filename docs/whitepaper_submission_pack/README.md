# Label Studio 白皮书投递包（正式排版版）

生成日期：2026-04-01  
目录：`docs/whitepaper_submission_pack`

## 文件清单

1. `融资版_白皮书.md`  
适用对象：投资机构、董事会、战略投资方。  
风格重点：市场机会、竞争壁垒、增长飞轮、资金使用、风险对冲。

2. `客户售前版_白皮书.md`  
适用对象：客户业务/技术负责人、采购、安全合规团队。  
风格重点：客户痛点、解决方案、实施路径、ROI、服务机制。

3. `内部立项版_白皮书.md`  
适用对象：内部管理层、研发委员会、信息安全委员会。  
风格重点：立项必要性、目标范围、资源预算、治理机制、验收标准。

## 三份文档均包含的正式结构

1. 封面页  
2. 目录页  
3. 正文章节  
4. 统一术语页  
5. 附录 A：指标口径  
6. 附录 B：实施清单

## 交付前 5 分钟替换项

1. 联系人、邮箱、电话。  
2. 编制单位/牵头部门名称。  
3. 建议密级与流转范围。  
4. 预算与资源（内部立项版）。  
5. 客户/投资人名称（如需定制版本）。

## 推荐导出方式

1. 用 Markdown 编辑器打开对应文件，替换上述字段。  
2. 导出 PDF（建议 A4、页边距统一）。  
3. 对外发送前执行法务与合规审阅。
